## 🚀 Run Locally

Follow these steps to run the portfolio on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/snehaa94/My_Portfolio_.git
```

**2. Open the project folder**

```bash
cd My_Portfolio_
```

**3. Open the website**

Open the `index.html` file in your browser.

No additional framework or package installation is required for this static HTML, CSS, and JavaScript website.
